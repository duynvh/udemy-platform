# T01: Maven parent and wrapper

Phase 1 · Size S · Dependencies: none

**Description:** Create the Maven parent in `backend/` that pins all versions and plugins for every Java module. Add the Maven Wrapper and project-only Maven settings in `backend/`. Add the repository hygiene files in the root.

**Acceptance criteria:**
- [ ] `backend/pom.xml` (packaging `pom`) imports the Spring Boot 4.0.x, Spring Cloud 2025.1.x, Spring Modulith 2.0.x, and Testcontainers BOMs; Java release 25.
- [ ] Plugins configured: Spotless (`palantir-java-format`), Surefire (`*Test`), Failsafe (`*IT`), JaCoCo (80% line rule on `**/domain/**` and `**/application/**`, fails `verify`).
- [ ] Project-only Maven settings use Maven Central: `backend/.mvn/settings.xml` defines Maven Central only; `backend/.mvn/maven.config` loads it as user and global settings. The developer's global or company settings have no effect.
- [ ] Root `.gitignore` (target, node_modules, `infra/.env`, IDE files), `.gitattributes` (`*.sh text eol=lf`), `.editorconfig`.

**Verification** (run in `backend/`; Windows: `mvnw.cmd` in place of `./mvnw`):
- [ ] `./mvnw -v` prints Maven 3.9.x and Java 25
- [ ] `./mvnw spotless:check` passes
- [ ] `./mvnw validate` passes and downloads only from Maven Central

**Files:**
- `backend/pom.xml`
- `backend/mvnw`, `backend/mvnw.cmd`, `backend/.mvn/wrapper/maven-wrapper.properties` (generated by `mvn wrapper:wrapper` in `backend/`)
- `backend/.mvn/settings.xml`, `backend/.mvn/maven.config`
- Root `.gitignore`, `.gitattributes`, `.editorconfig`
